# mero-stream

Native Android Views search and episode list with platform VideoView playback. No browser engine, shell runtime, or website JavaScript. Initial provider extraction adapted from ani-cli (GPL-3.0); see LICENSE.

Upstream inspected: https://github.com/pystardust/ani-cli/tree/8527f185a12c6b5d0247a30b2217000dd65457fe

See [architecture, provider details and acceptance milestones](../docs/apps/mero-stream.md). Mero TV remains a separate application.
